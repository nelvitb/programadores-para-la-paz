El login es el proceso mediante el cual una persona demuestra su identidad para ingresar a una aplicación. Gracias a este mecanismo, el sistema puede reconocer a cada usuario y permitir únicamente las acciones que le corresponden. Algunas secciones deben permanecer protegidas para evitar modificaciones no autorizadas o el acceso a información interna. Además, nunca deberían mostrarse datos como contraseñas, documentos de identidad, direcciones, números telefónicos o cualquier información sensible de la comunidad.
