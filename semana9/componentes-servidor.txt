Sistema operativo:
Es el software encargado de administrar los recursos del computador o servidor. Permite ejecutar aplicaciones y controlar el funcionamiento del sistema.

Node.js:
Es un entorno que permite ejecutar código JavaScript en el servidor. Facilita la creación de aplicaciones y APIs.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y las respuestas que reciben los usuarios.

Puerto:
Es un punto de comunicación donde el servidor recibe solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del sistema. Ayudan a detectar errores y monitorear el funcionamiento del servidor.
